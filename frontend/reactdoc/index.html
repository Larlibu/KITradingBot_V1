api

Erstellt eine konfigurierte Axios-Instanz für die Kommunikation mit dem Backend. Diese Instanz wird verwendet, um alle API-Anfragen an den Java Spring Boot Service zu senden.

fetchMarket(limit: number, symbol: string): Promise<Array<object>>
Parameters

Returns
Promise<Array<object>>: Eine Liste von Candle-Objekten.
